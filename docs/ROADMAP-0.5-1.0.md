# HPS cumulative implementation roadmap

## v0.5
Institutional account objects, organization membership, exact-file registry lookup and compact trust mark.

## v0.6
Authorized issuer roles, institution keys, institution-signed records, parent/version lineage, supersession and revocation.

## v0.7
Private evidence vault, signed attestations and reusable TypeScript SDK.

## v1.0
Canonical claim signing, registry countersigning, VC-compatible export and C2PA assertion mapping.

The codebase in this package represents the **cumulative v1.0 target**. SQL migration files retain the upgrade sequence so an existing v0.4 database can evolve incrementally.
