# Privacy Policy text to add

Because Content Integrity Witnesses deliberately store selected critical values
from an original document, the public privacy policy should disclose this
before broad deployment.

Suggested addition to section **8. Documents and hashes**:

> **Content Integrity Witnesses.** Where a record owner or authorized issuer
> explicitly enables a Content Integrity Witness, HPS may store selected
> extracted critical values such as monetary amounts, dates, percentages and
> numbers together with hashed context anchors. This allows later verification
> of whether those registered values changed without storing or publicly
> reproducing the complete source document. The values shown in the witness
> preview are stored only after explicit confirmation by the authorized user.
> Candidate file bytes and complete extracted text are not uploaded by this
> feature.

Also update the verifier privacy note consistently if the feature changes in
future.
